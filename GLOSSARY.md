# Glossary

- **adoption** — A session that lost its client getting a client again. When an ACP client disconnects, its session stays alive with its history and its in-memory client MCP declaration, but its MCP servers are disconnected. When a client resumes that session, the declaration is restored and the servers reconnect at the next turn boundary. Example: after a shared-core restart, T3 sends one more prompt and the session's client MCP tools are back, in the same session.
- **apply tail** — The single queue on which a runtime applies, suspends, and closes client MCP configuration, one step after another. It exists so that a slow earlier step cannot overwrite a newer declaration. Example: credentials that arrive while a turn is running wait for the queue and take effect at the next turn boundary.
- **dispatch run** — A manual (`workflow_dispatch`) run of the `ci` workflow. The only run kind that assembles and uploads a `dist-runtime` artifact.
- **dist-runtime** — The frozen runtime directory `apps/zcode-cli/packages/cli/dist-runtime/` that the installed `piz` wrapper execs. Only the promotion scripts write it; it carries the PROMOTED_* markers.
- **OSC 7501** — Terminal program-status protocol (mitchellh.com/writing/program-status-osc7501). A program emits `ESC ] 7501 ; state=…[:kind=…][:app=…][:msg=<base64>] ESC \` on its own output stream; states are idle/working/done/blocked/error. Terminals and multiplexers may render them (badges/notifications); terminals that don't know the sequence ignore it.
- **override source** — The fork's wrapper around a session's normal MCP configuration. The upstream MCP session of a runtime reads only this wrapper. The wrapper decides what the session sees: the client's declaration when there is one, otherwise the normal disk and plugin configuration. Example: an ACP session created with `mcpServers` shows exactly those servers, even when the workspace has its own MCP file.
- **piz** — This maintained ZCode fork and its installed CLI command.
- **PROMOTED_CI_RUN** — Installed runtime marker containing the successful CI run that supplied the promoted artifact.
- **PROMOTED_FROM** — Installed runtime marker containing the original build commit, never relabeled to a later merge commit.
- **PROMOTED_ON** — Installed runtime marker containing the clean `main` commit whose Git tree was checked against the build at promotion time.
- **reconnect debt** — A flag that says "the MCP configuration is right, but its connections must be made again". The runtime sets it when a client disconnects, and when an identical declaration arrives with servers that are failed, disconnected, or missing. It clears the flag after one reconnect at the next turn boundary, so there is no retry on every turn. Example: after adoption the configuration did not change, so this flag is what starts the reconnect.
- **turn boundary** — The moment between two complete turns, when no turn is running, queued, or reserved. A client MCP declaration that arrives during a turn takes effect only here. Example: credentials sent during a multi-step turn are used by the next queued turn, never by the running one.
